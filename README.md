# Evolutionary Computing Projects Overview

This repository contains projects completed for the **Evolutionary Computing** course, focusing on evolutionary algorithms and optimization techniques.

---

## Assignments

### **Assignment 1: Evolutionary Strategies**
- **Objective**: Implement evolutionary strategies for optimization problems.
- **Topics**: Mutation, selection, and fitness evaluation.
- **Outcome**: Designed and analyzed strategies for solving benchmark problems.

### **Assignment 2: Neuroevolution with Evoman Framework**
- **Objective**: Train neural networks using genetic algorithms in the Evoman game.
- **Topics**: Neuroevolution, fitness-based selection, and optimization.
- **Outcome**: Evolved neural networks to achieve competitive performance in gameplay.

---

## Repository Structure
- **`Assignment1_Group81/`**: Evolutionary strategies implementation.  
- **`Assignment2_Group81/`**: Neuroevolution experiments.  
- **`evoman_framework-master/`**: Evoman framework for training and evaluation.

---

## Tools and Technologies
- **Python**, **NumPy**, and the **Evoman Framework** for implementing and running experiments.
